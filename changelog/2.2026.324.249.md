This release resolves critical issues with payment processing, payroll calculation options, and pending claim input validation. (*249*)

<!-- truncate -->

## Bug Fixes

- Fixed **Maybank2E-RC Universal Payment** format not supporting GIRO mode for Merchantrade (#6405)
- Fixed month-end payroll incorrectly including both default and pending wages when "Include default wages in addition to pending transactions" option is unchecked (#6404)
- Fixed **Pending Claim** unable to accept more than 2 decimal places in the **Rate** field (#6403)
