This release adds Drive reminders and paysheet validation, revises Time Attendance Summary, and fixes pending claim, wages, and overtime issues. (*249*)

<!-- truncate -->

## Features

- Added Drive user information sync, with reminders when Drive storage is low or the account is nearing expiry
- Added validation of **Paysheet** Gross Pay and Gross Deduct amounts before saving (#6407)

---

## Updates

- Added an "Invalid URL" error when an attachment URL is empty
- Revised work schedule reminder generation to run upon logon
- Revised the **Time Attendance Summary** data form
  - Display **Actual In** and **Actual Out** time
  - Hide Session 3 and Session 4 columns by default
- Added a footer count to the abnormal time attendance summaries reminder list
- Disabled printing on **IR8A**, **Appendix 8A**, and **Appendix 8B** entry forms

---

## Bug Fixes

- Fixed access violation in **Pending Claim** when clicking the **Code** dropdown (#6412)
- Fixed incorrect **Time in Minute** values for **Pending Wages** (#6410)
- Fixed inability to remove a Drive share link when the user's Drive account is disabled
- Fixed "catastrophic failure" error when processing leave entitlement
- Fixed "Cannot access field 'Rate' as type boolean" error when appending an overtime record to a paysheet (#6408)
- Fixed missing `TA_TRANS` records caused by an exception from Pending OT and Leave
- Fixed access violation caused by a missing summary
- Fixed inability to post a time attendance overtime record to **Pending OT** when more than one record exists for the same employee on the same date with the same start time
- Fixed **Attendance Reward** not saving the last selected `PICode`
