This release adds Employee Name grouping to Payroll Summary, introduces PB Enterprise DuitNow ECP Payroll Excel format, and resolves multiple bank file, PCB, and TMS bugs. (*246*)

<!-- truncate -->

## Features

- Added grouping by **Employee Name** to **Payroll Summary** report (#6367)
- Added **PB Enterprise DuitNow ECP Payroll Excel** format (#6317)
- Added **Birthday Month** column to **Employee** browse form (#6362)

---

## Updates

- Updated **Maybank2E-RC Universal Payment** format bank code list (#6381)
- Added **Amount** and **SKBKK** fields to detail records in **Alliance Bank** SOCSO payment file format (#6380)
- Renamed **Employer Share (Employment Injury)** to **Employer Share** on SOCSO table (#6377)

---

## Bug Fixes

- Fixed unable to process TMS log for rest day
- Fixed unable to reset Public Holiday's clock method to GPS when clearing all
- Fixed OT code (HW30) rate incorrectly set to 3.0 instead of 2.0 in existing database
- Fixed unable to save grid layout on **Claim** transaction entry form
- Fixed "Reference No" column containing symbol in **UOB SOCSO** file format (#6382)
- Fixed pending transaction being processed before saving to table
- Fixed footer sum including the footer row in **Public Bank** Excel file formats
- Fixed employee address lines partially populated in **CP22** file (#6315)
- Fixed **PCB Adjustment** not allocated to **PCB Normal** when both PCB Normal and PCB Additional are zero (#6378)
