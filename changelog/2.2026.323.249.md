This release enhances Singapore payroll reports with improved IR8A and CPF handling, fixes form tab issues, and resolves critical access violations. (*249*)

<!-- truncate -->

## Features

- Added datamap to **Print Paysheet** for Singapore

---

## Updates

- Updated **IR8A** report to exclude employees not in the payroll for the year
- Updated **Excess CPF Contribution** report with revised **CPF Table Format**
- Renamed "**CPF Contributed**" to "**CPF Contribution**" in **Excess CPF Contribution** report

---

## Bug Fixes

- Fixed access violation when printing **Excess CPF Contribution** report for foreign employees
- Fixed **IR8A** form overwriting records
- Fixed **IR8A**, **A8A**, **A8B** forms opening multiple tabs for the same form
- Fixed incorrect values for "Gains or profits under S10(1)(g)" in **IR8A** report
- Fixed **Maintain Frequency** menu item missing, preventing Ad Hoc payroll processing (#6401)
