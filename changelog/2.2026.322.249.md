This release introduces **Singapore** payroll web app support, upgrades the database to version 156, and enhances time attendance and payroll calculation features. (*249*)

<!-- truncate -->

## Database

Database upgraded to version **156**

---

## Features

- Added **Singapore payroll & web app** support
- Added **BasisType** field to **Maintain Wages**
- Added **JTKSM Borang PA 1, PDA 2** forms for Malaysia
- Added alert if **Non-Employment Injury Scheme** is not selected (#6397)

---

## Updates

- Updated **Leave App Log** sync to automatically check and sync logs if not synced during initial setup
- Revised **Time Attendance Summary** and **Unassigned Listing** report validation based on SQL View
- Revised `TAppSession.AccessRightItems` to prevent access violations when session setup lacks access rights
- Updated incomplete month pay calculation to base on working days from **Maintain Calendar**
- Updated time attendance logic to consider clock out time when determining `CalendarDate`

---

## Bug Fixes

- Fixed abnormal time attendance summaries not prompting upon logon
- Fixed **Time Attendance Summary** clock status incorrectly showing "Absent" when leave is applied
- Fixed payroll process incorrectly prorating employee's fixed PTPTN deduction for partial month (#6398)
- Fixed `TA_Trans` records being posted to Pending OT/Leave Application when `TransDate >= IncDay(Now, -1)`
- Fixed **Alliance Bank BizSmart Bulk Payment** file format missing bank codes (#6399)
